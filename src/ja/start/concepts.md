# 基本概念

Formulon は Excel を起動せずにスプレッドシートのファイルを処理します。パッケージを選ぶ前に、計算エンジン、その周囲の操作画面やツール、共通して扱うワークブックの役割を確認します。

## 目的に合う製品を選ぶ

| 製品 | 担当する処理 | 最初に読むページ |
| --- | --- | --- |
| Formulon | ワークブックの読み込み・編集、数式の評価、再計算、ファイルへの保存 | [実行入口を選ぶ](/ja/start/choose-runtime) |
| formulon-cell | Formulon エンジンを使い、ブラウザ内に編集可能な表計算画面を表示 | [スプレッドシートの組み込み](/ja/cell/install) |
| formulon-mcp | ローカルサーバーのツールを通じて、AI クライアントからワークブックを操作 | [MCP クライアントの接続](/ja/mcp/install) |

エンジンは単独で使えます。Cell と MCP はエンジンに機能を加えます。Cell は画面を更新し、MCP はセッションやファイルパスを管理します。アプリケーションが直接呼び出す製品のガイドを参照してください。

## ワークブック・シート・セル・範囲

ワークブックには、ワークシートと、スタイルや定義名などの共有データが含まれます。セルはシート上の行と列で決まる位置です。範囲はセルを長方形にまとめた領域です。

A1 形式のアドレスは、行が 1、列が A から始まります。API に数値で渡す座標は 0 から始まります。シート名とシート番号は別の情報で、最初のシート名が常に `Sheet1` とは限りません。

| 最初のシート名が `Sheet1` の場合のアドレス | シート番号 | 行番号 | 列番号 |
| --- | --- | --- | --- |
| `Sheet1!A1` | 0 | 0 | 0 |
| `Sheet1!B2` | 0 | 1 | 1 |
| `Sheet1!A1:B2` | 0 | 0〜1 | 0〜1 |

範囲の終端を含みます。最後の例は 4 セルです。範囲をオブジェクトで渡す場合は、呼び出す API のプロパティ名を使ってください。エンジンの範囲と Cell の表示範囲では、プロパティ名が異なります。[ワークブック操作](/ja/workbook/operations) と [Cell の設定オプション](/ja/cell/options) を参照してください。

## 数式・計算結果・表示文字列を区別する

A1 に `100`、B1 に `=A1*2` が入っている例で考えます。

| 要素 | 例 | 意味 |
| --- | --- | --- |
| 直接入力した値 | A1 の `100` | 保存された数値です。数式ではありません |
| 数式の文字列 | B1 の `=A1*2` | エンジンが評価する式です |
| 計算結果 | 再計算後の B1 の `200` | 数式セルのキャッシュに保持される値です |
| 表示形式 | `0.00` | 数値をどのように表示するかを指定します |
| 表示文字列 | `200.00` | 書式を適用した文字列です。元の値は数値の `200` のままです |

`#DIV/0!` のようなエラーもスプレッドシートの値です。存在しないシート番号を指定した場合など、API 呼び出し自体の失敗とは区別します。[エラーモデル](/ja/compatibility/errors) を参照してください。

## 編集と再計算は別の手順

A1 を `150` に変更すると、B1 は再計算待ちになります。エンジンを直接呼び出す場合、値の読み取りや保存だけでは再計算されません。`recalc()` を呼び出して成功を確認すると、B1 の値が `300` になります。

ファイルの読み込み直後は、ファイル内のキャッシュ値を読み取ります。全体の再計算はワークブックを更新します。部分再計算は指定した出力セルとその計算に必要な参照元を更新し、それ以外は再計算待ちのまま残します。Cell と MCP には、操作の一部として再計算する機能があります。すべての読み取りで再計算されるとは限らないため、各操作の既定値を確認してください。[ライフサイクル](/ja/workbook/lifecycle)、[再計算](/ja/workbook/recalculation)、[MCP ワークフロー](/ja/mcp/workflow) で詳しく説明しています。

## 「プロファイル」と「ロケール」の違い

| 設定 | 変わるもの |
| --- | --- |
| Excel 互換性プロファイル（例: `win-365-en_US`） | 計算の挙動、文字列比較、地域設定に依存する書式 |
| Cell の UI ロケール（例: `en`、`ja`） | 操作画面の翻訳。`setLocale()` はワークブックの計算プロファイルも連動して変更します |
| Cell の UI プロファイル（例: `embedded`、`full`） | 表示する操作部品や有効にする機能 |

これらの設定は、実行する言語やパッケージを選ぶものではありません。UI プロファイルは、計算の互換性や翻訳とは別に操作部品を選びます。

保存する数式の関数名は共通の英語表記です。画面に表示する数式は地域に合わせて変換し、保存前に共通表記へ戻せます。計算プロファイルは実行時の設定なので、読み込み後に再適用します。プロファイルを選んでも保存済みの関数名は翻訳されません。[数式の言語](/ja/workbook/language) と [言語切り替えデモ](/ja/cell/language-switching) を参照してください。
