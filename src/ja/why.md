# Formulon とは

Formulon は、Excel を組み込まずにスプレッドシート計算を実行したい製品のためのヘッドレス計算エンジンです。1 つの C++17 core を WebAssembly、Python、CLI、ネイティブ組み込みから利用します。

互換性は測定可能なものとして扱います。既定プロファイルは `win-365-ja_JP` で、実際の Excel から取得した oracle データにより挙動を固定します。

## 解決すること

- サービス、ジョブ、ノートブックで `.xlsx` / `.xlsb` を再計算する。
- ブラウザや worker 内で Excel 風の数式を評価する。
- ブラウザ、Python、CLI、ネイティブで同じ core を使い、結果のずれを防ぐ。
- 計算値を更新しつつ、ワークブック構造を保持する。
- バージョン管理された Excel 由来の期待値で数式挙動を検証する。

## やらないこと

Formulon は UI、チャート描画、VBA ランタイム、PowerQuery、DAX、旧 `.xls` 実装ではありません。この境界により、計算エンジンを小さく検証しやすく保ちます。

## 現在の状態

Formulon は開発中で、まだ安定版ではありません。522 件の関数カタログはすべて登録済みで、ファイル形式層と各実行環境の binding も動いていますが、API と package layout は安定版まで変わる可能性があります。業務上重要なワークブックは、対象 Excel プロファイルに対する検証ファイルで確認してください。
