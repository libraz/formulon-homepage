# ファイル形式サポート

## 概要

::: info 読み込み / 書き出し / 保持は別の概念です
読み込みは構造を解釈できること、書き出しは構造を出力できること、保持は往復保存で失わないことです。計算に影響するのは、評価対象として実装されている機能だけです。
:::

| 領域 | 状態 |
| --- | --- |
| `.xlsx` 読み込み | ワークブック、シート、セル、スタイル、共有文字列、リレーションシップ、テーブル、定義名、コメント、スレッドコメントと人物一覧、ハイパーリンク、結合、型付き AutoFilter、入力規則、条件付き書式、ピボット構造、描画オブジェクト、画像に対応 |
| `.xlsx` 書き出し | 上の読み込み行に挙げたモデル化済みの構造と、型付き AutoFilter / 画像の編集を書き戻し、可能な未モデル化パーツを保持。重要な構造は出力パッケージで確認 |
| 入力規則の評価 | `validateValue()` は明示した入力候補を確認し、`listInvalidCells()` は保存済みセルの値を確認する。どちらもセルを変更せず、編集時に入力規則を自動で強制しない |
| `.xlsb` 読み込み / 書き出し | スタイル、行 / 列レイアウト、結合、`date1904`、表示倍率 / ウィンドウ枠固定、動的配列メタデータ、対応するトークン化数式、条件付き書式、入力規則、シート / ワークブック保護のメタデータをモデル化して出力。XLSB から読み込んだ AutoFilter は不透明なワークシート末尾として保持し、型付きの変更は保留して報告。従来型ノート、スレッドコメント、OOXML の描画は XLSB 保存時に省略して報告。詳細は [XLSB の制限](/ja/workbook/file-formats#xlsb) を参照 |
| `.xlsm` のマクロバイト | 保持するが実行しない |
| 旧形式の `.xls` | 対象外 |
| パスワード保護されたパッケージ | 復号しない。暗号化されたワークブックも旧形式の `.xls` も OLE 複合ファイルで、どちらを読み込んでも `kIoZipEncrypted` で失敗する。先に復号するか `.xlsx` へ変換する |
| グラフ / 図形の描画 | 対象外。XLSX では画像バイトとアンカーを検査、読み取り、挿入、削除でき、描画オブジェクトを列挙できるが、グラフ、図形、グループは描画しない |
| 元シートまたは外部データからのピボットキャッシュ更新 | 対象外。対応済みキャッシュの保持・投影は対象 |

CLI は `-o` のファイル拡張子で出力コンテナを選びます。バインディングは `saveAs(format)` / `save_as(fmt)` に渡す `WorkbookFormat` で選びます。読み込みはパッケージの内容を調べるため、入力ファイルの拡張子では形式を決めません。

## 読み込みの上限

読み込み時にはパッケージの展開量に上限があり、細工されたファイルはメモリを使い果たす前にホストステータスで失敗します。

| 上限 | 値 | 超えたときのステータス |
| --- | --- | --- |
| パッケージ内の 1 パーツの展開後サイズ | 100 MiB（圧縮率の検査もあり） | `kIoZipBomb` |
| 1 回の読み込みで展開する全パーツの合計 | 256 MiB | `kIoFileTooLarge` |
| `.xlsx` の 1 ワークシートに格納するセル | 約 298 万（書き込まれた座標ごとに数える。`.xlsb` は対象外） | `kIoFileTooLarge` |

## 保持ルール

XLSX では、上の表に示した型付き AutoFilter と画像操作を Formulon が意味を解釈します。グラフ、図形、グループは構造データとして扱い、描画は別のツールに任せます。XLSB では、パッケージから読み込んだ AutoFilter は不透明なまま保持し、型付きの変更を保留します。従来型ノート、スレッドコメント、OOXML の描画は XLSB 保存時に省略します。ページ設定、余白、印刷オプション、ヘッダー / フッター、手動改ページ、テーブル、既定以外の計算設定も保留します。詳しくは [ファイル形式](/ja/workbook/file-formats#xlsb) を参照してください。`saveWithDiagnostics()` / `save_with_diagnostics()` の `deferredFeatureCount` / `deferred_feature_count` で保留された機能を確認できます。そのほか、Formulon が意味を解釈しない機能は可能な範囲でパッケージ構造を保持するため、作成や描画は別のツールが担当できます。

## 計算ルール

再計算へ影響するのは、計算エンジンが表現している機能だけです。`evaluateAutoFilter()` と `validateValue()` は明示的に呼び出したときだけ判定します。`applyAutoFilter()` は行の表示状態を変更し、依存する `SUBTOTAL` / `AGGREGATE` 数式を再計算待ちにします。更新後の値を読む前に `recalc()` を呼び出してください。`validateValue()` は入力候補を保存しません。保持される構造が自動的に解釈されるわけではありません。

この対応表の API 境界は、[フィルターと入力規則](/ja/workbook/filters-validation)、[コメントと画像](/ja/workbook/comments-images)、[表示とレイアウト](/ja/workbook/presentation) で説明しています。
