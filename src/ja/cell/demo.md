# formulon-cell デモ

このデモは formulon-cell を使い、サンプルデータ入りのワークブックを表示します。編集、範囲選択、メニューとダイアログ、テーマ切り替え、表示する UI 部品を試せます。

グラフを試すには `A1:C9` を選択し、挿入リボンからグラフを選びます。選択範囲が項目と系列に分かれる仕組みは[グラフガイド](/ja/cell/charts)を参照してください。

アプリケーションへ埋め込む場合は [埋め込み](/ja/cell/embedding) からプロファイルを選び、ホストに必要なオプションと拡張だけを追加してください。フレームワークとの連携は [React / Vue アダプター](/ja/cell/frameworks) を参照してください。

フルデモのヘッダーには `既定`、`Mac`、`自動` の UI プラットフォームセレクターがあります。選択を変えると `setUi()` が呼ばれ、同じワークブックをマウントしたままプラットフォーム UI を再解決します。初期データには `Region`、`Revenue`、`Cost`、`Margin` の見出しがあり、`B2:B9` と `C2:C9` は数値、`D2:D9` には `=B2-C2` のような数式が入っています。

`Mac` を選ぶと描画タブ、現在の関数カタログをカテゴリ別に表示する引数ピッカー、データと校閲タブのダイアログを試せます。引数ピッカーには最近使った関数も表示されます。使える操作と制限は [プラットフォームと Mac UI](/ja/cell/platform) を参照してください。描画のインクはセッションだけに存在し、`.xlsx` には保存されません。`Ctrl` または `Cmd` を押しながらドラッグして 2 つ目の範囲を追加し、`Ctrl+Enter` または `Cmd+Enter` で選択したすべての範囲へ入力できます。リボンの書式設定、クリア、名前付きスタイル、セルの書式設定ダイアログの下線セレクターは、各範囲が認可されている場合に選択範囲全体へ適用されます。

数式バーの下にある言語セレクターは `ui.features.localeSwitcher: true` で有効にした組み込みのコントロールで、English、日本語、Deutsch、Français、中文、한국어、ไทย を切り替えます。言語を変えると UI 辞書と計算プロファイルが一緒に切り替わり、ワークブックはマウントされたまま残ります。たとえば `Deutsch` を選ぶとリボンがドイツ語になり、`B10` の数式は `=SUMME(B2:B9)`、`C11` の平均は `4373,75`、`B12` のマージン率は `38,8%` と表示されます。保存される数式は `=SUM(B2:B9)` のままです。ヘッダーの UI プラットフォームを `Mac` に切り替えても選んだ言語は維持され、プロファイルは `mac-de_DE` になります。言語と計算プロファイルの対応は [言語の切り替え](/ja/cell/language-switching) を参照してください。
