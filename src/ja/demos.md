# デモ

どのデモも、ブラウザー内で実際のエンジンが動きます。サーバーには何も送信しません。このページはリンクだけを並べているので軽く開けます。解説を読むときは、各デモのあるページを開いてください。

## 数式と再計算

- [数式を評価する](/ja/start/evaluate): 数式を入力し、エンジンの結果と値の種類を確認できます。`#DIV/0!` などのエラーが値として返ることも見られます。
- [ワークブックを再計算する](/ja/start/recalculate): `.xlsx` を読み込むかサンプルを生成して再計算し、保存したバイト列をダウンロードできます。同じデモは[ブラウザーでのワークブックアップロード](/ja/scenarios/browser-upload)にもあります。
- [依存関係の追跡](/ja/workbook/recalculation): 数式の連鎖でセルを選択し、先行セルと依存セルを深さを変えながら確認できます。
- [反復計算](/ja/workbook/recalculation): 循環参照を解き、許容誤差を変えると残差の曲線がどう変わるかを見られます。

## ワークブック機能

- [動的配列](/ja/workbook/dynamic-arrays): 配列数式のスピル範囲をプレビューし、シートに反映できます。`#SPILL!` になる場合も試せます。
- [ピボットテーブル](/ja/workbook/pivots): ピボットテーブルを設定し、エンジンが投影するセルを確認できます。
- [行と列の挿入・削除](/ja/workbook/operations): 構造を編集し、編集前後の数式を比べられます。`#REF!` になる参照も確認できます。
- [XLSX と XLSB の往復](/ja/workbook/file-formats): 1 つのワークブックを両方のコンテナーに書き出し、それぞれ読み戻せます。

## 互換性

- [関数検索](/ja/compatibility/formula-coverage): 動作中のエンジンから読み出した関数カタログを検索し、引数の数と実装状況を確認できます。
- [エラーモデル](/ja/compatibility/errors): 数式のエラー値と、不正なバイト列を読み込んだときのホスト側の失敗を見比べられます。

## formulon-cell の UI

- [フルスプレッドシートデモ](/ja/cell/demo): サンプルのワークブックを編集し、メニューとダイアログ、テーマ、プラットフォーム UI の切り替え、表示する部品の変更を試せます。
- [読み取り専用のレポートビューア](/ja/cell/embedding): 表示範囲を固定し、選択とコピーだけを許可した埋め込みです。
- [入力セルを限定したフォーム](/ja/cell/embedding): 指定したセルだけが入力を受け付けるシートです。
- [UI プロファイル](/ja/cell/options): 再マウントせずに `setUi()` で表示密度と周辺 UI を切り替えられます。
- [ホスト更新とイベント](/ja/cell/host-integration): ホストから値を反映し、シートが発行するイベントを確認できます。
- [テーマとロケールの切り替え](/ja/cell/theming): マウント済みのシートでテーマと UI 辞書を切り替えられます。
- [native dialog 内のオーバーレイ](/ja/cell/modals): シートと浮動 UI を 1 つのダイアログの境界内に収めます。
