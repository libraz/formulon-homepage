# Internationalization

The UI includes `en` and `ja` dictionaries. Set the initial locale with `locale`, change it through `instance.i18n.setLocale()`, and override labels with `strings` or `extend()`. These operations update the mounted UI without rebuilding the spreadsheet.

## Set the initial locale

```ts
const instance = await Spreadsheet.mount(host, {
  locale: 'en',
})

instance.i18n.setLocale('ja')
```

If no locale is supplied, the controller starts with the `ja` dictionary. Pass the locale that matches the surrounding application when the host owns language selection.

## Override labels

Use `strings` for mount-time label overrides or `i18n.extend()` for an update after mount. The object is a deep partial of the public `Strings` type.

```ts
const instance = await Spreadsheet.mount(host, {
  locale: 'ja',
  strings: {
    contextMenu: {
      copy: 'コピー',
      paste: '貼り付け',
    },
  },
})

instance.i18n.extend('ja', {
  contextMenu: {
    copy: 'コピーする',
  },
})
```

An `extend()` override belongs to the locale named in the call. Switching away and back keeps that locale's override in the instance. The package dictionaries are not modified globally.

React and Vue users can pass the same `strings` object through the component prop. `useI18n()` returns the active locale and resolved dictionary for host controls that need matching labels.

## Register a host locale

`register()` adds a complete dictionary under a host-defined locale id. Use the exported `Strings` type when building it so the dictionary stays aligned with the package declarations.

```ts
import { Spreadsheet, type Strings } from '@libraz/formulon-cell'

const fr: Strings = loadFrenchDictionary()
const instance = await Spreadsheet.mount(host, { locale: 'en' })

instance.i18n.register('fr', fr)
instance.i18n.setLocale('fr')
```

For a small product-specific vocabulary, extending `en` or `ja` is usually simpler than maintaining a complete dictionary. A registered dictionary can be loaded from JSON or a translation bundle before `setLocale()`.

## Subscribe to locale changes

`i18n.subscribe()` is useful inside an extension or a host-owned control. The spreadsheet instance also emits `localeChange`, which is convenient for persistence.

```ts
const off = instance.on('localeChange', ({ locale }) => {
  localStorage.setItem('spreadsheet-locale', locale)
})

const saved = localStorage.getItem('spreadsheet-locale') ?? 'en'
instance.i18n.setLocale(saved)
```

Call the returned function when the host control is removed. Framework adapters clean up their `useI18n()` or `useSpreadsheetEvent()` subscriptions with component lifetime.

## UI locale and formula display

The controller supplies labels for the grid controls, dialogs, menus, and extensions. Function names and descriptions shown by formula assistance can be supplied separately through `WorkbookHandle.setFunctionMetadataProvider()` when the application has a localized catalog. The UI locale setting remains the source for UI labels.
